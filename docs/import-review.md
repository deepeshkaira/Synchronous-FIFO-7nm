## Source and script observations

- The supplied FIFO uses `clk` with separate read/write enables. Manual gate instances are commented out. This is the shared RTL for synthesis with and without automatic clock gating.
- The gated script uses `compile_ultra -gate_clock`, integrated gates, minimum width 1, and control point `before`. The ungated script uses `compile_ultra`.
- Both PrimeTime scripts read the same `saif/sync_fifo.saif`, but write to separate result folders. They report switching activity before `update_power`; final propagated clock activity still needs review.
- The ungated synthesis script separates most reports, but its `check_design` and clock-gating reports share paths with the gated script and can overwrite them. Preserve each run's copies before rerunning.
- The supplied SDC files were generated by `write_sdc` and belong under `netlist/`. They are not replacements for the missing original `constraints/sync_fifo.sdc`.
- The Questa script uses seed 12345 and starts activity collection after `run 16ns`. Its comment assumes reset release at 15 ns and first traffic at 20 ns. The testbench is needed to verify that timing.
- Questa writes `saif_reports/sync_fifo.saif`; PrimeTime reads `saif/sync_fifo.saif`. These are different paths in the supplied flow.
- The screenshot shows FIFO traffic and flags, but has no UVM completion summary. It does not prove all cases were covered or that no errors occurred.
